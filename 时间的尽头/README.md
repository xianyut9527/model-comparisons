# 时间的尽头

> 本文件夹用于存放「时间的尽头」这一主题的模型对比结果。


提示词:
  请制作全屏交互 3D 单页「时间的尽头 / THE END OF TIME」，单个自包含 HTML，Three.js 从 CDN 引入，中文衬线字体用 Noto Serif SC。整体是紫黑渐变天幕 + 铜橙金色 + 奶油色文字的电影片头气质，克制、庄重。

【界面】
- 左侧：「最后一秒 / THE LAST SECOND」小标题（金色、宽字距、前带短横线）；超大标题「时间的 / 尽头」；副标题「所有的星都熄灭了。/ 最后一秒还在燃烧。」；奶油底深色字按钮「触发潮汐 | SPACE」。进场时这四项依次淡入，只做这一次入场动画。
- 左上 Logo + THE END OF TIME；右上声音、重置两个圆形按钮；右下 HUD「时间相位 / T +00.00 s / 进度条 / 三个阶段标签（余烬、回响、坍缩）」；左下操作提示「拖拽 环绕 / 滚轮 缩放 / 点击 潮汐」。
- 整页一圈极细金边，左上与右下各有小直角标记；四周轻微暗角。手机竖屏时文字移到下方、黑洞上移，隐藏 HUD 与提示。

【3D 主体，位于画面右侧】
1. 天幕：全屏着色器，顶部深紫黑，地平线偏暖紫，黑洞周围有淡紫色云雾。
2. 黑洞：camera-facing 平面 + 片元着色器。纯黑视界（边缘带轻微透镜形变，不是正圆）；上亮下暗的光子环；三组不同倾角的椭圆吸积光丝（细密同心条纹、差速旋转，第三组很淡）；紫色外晕。视界要遮挡后方物体。
3. 钟环：围绕黑洞的破碎铜色表盘，9–11 段 ExtrudeGeometry 圆环扇形，长度和缝隙随机，部分错位倾斜；铜色带自发光，被黑洞方向的橙色点光源照亮；外沿有淡色刻度线，内沿有一条发亮细边；表面有罗马数字（缺失的段不显示）。另有金色细环和黑色金属弧环倾斜环绕；中间有两根尖头细长指针缓慢走动。
4. 漂浮碎石约 55 块，4 种不规则低面数变体，绕黑洞公转并自转；绕黑洞旋转的尘粒约 2200（越近越快）；约 1800 颗远景星点闪烁；少量失焦的暗淡光斑作前景。
5. 荒原：昏暗地面，散落约 130 块低多边形扁平岩板和 8 块倾斜石碑，被雾吞没。

【交互】
- 点击画面 / 点按钮 / 按空格触发「潮汐」：金色波浪形冲击波多层扩散，迸出约 400 颗金色火星；钟环碎片和碎石被冲散后用弹簧阻尼慢慢回位；黑洞光环、铜环、点光源短暂变亮；时间加速；镜头推近并环绕摆动（FOV 轻微冲击）加轻微抖动。开场约 3 秒自动触发一次。
- 镜头：开场环绕推近；鼠标移动视差；拖动环绕、滚轮缩放；点击与拖动要区分。
- 声音按钮：低频嗡鸣（WebAudio），潮汐时低音下坠；重置按钮：时间、镜头、状态归零。
- HUD：T 计时实时更新，进度条循环，三个阶段随进度高亮。

【要求】全部程序化生成，不使用外部图片；按钮有键盘焦点样式；保持 60fps。充分发挥顶尖审美、艺术设计与 3D 编程能力，在构图、光影、材质、粒子效果、动画、空间氛围上做到极致。画面需要极具视觉冲击力，用户可以通过鼠标自由交互。
